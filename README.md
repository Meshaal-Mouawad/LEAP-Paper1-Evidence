# LEAP Paper 1 — Public Research Evidence

This package contains a screened subset of the verified Paper 1 results and scoring code.

## Included
- Aggregate formula and KPI-page statistics and research-question evidence summary.
- Frozen prospective scorer source and recorded scoring outputs for three matching variants.
- Original experiment scoring code and summary results.

## Scope
The underlying frozen 355-file third-party source corpus, source-level annotations,
individual reviewer records, full prediction inputs, and private adjudication records
are **not included** in this public package. The scorer scripts require additional
frozen inputs for a complete independent replay. This is a **public evidence subset**,
not the complete reproducibility archive.

## Source
Prepared from the author-provided P6R16 S1 Results and S2 Reproduction archives.
Original selected file bytes are unchanged.

## Citation
LEAP Paper 1, author Meshaal Mouawad. Cite the published article when available.

## Data and code availability
Link to this repository as a partial public evidence release. Do not claim full
reproducibility or full research-data deposition on the basis of this package.
